# 数据处理边界

本文件描述当前实现，不替代正式上架时的隐私政策或所有者合规审查。

任务的目标、输入、附件与执行结果保存在用户配置的 Host 工作目录和 SQLite 中。iPhone 保存草稿、上传状态、原生执行回执、交互偏好和观察日志；配对 token 保存在 Keychain。

调用外部模型时，相关目标、上下文、工具定义和必要材料会发送到配置的 Provider。配置 Mem0 后，长期记忆检索与写入会经过该服务，不应描述为“所有数据只在手机本地”。其他 API、MCP、CLI 各有自己的处理边界。

观察模式须由用户显式选择来源并启动；转写文字与必要关键画面可发送到 Host 和配置的 AI 服务。当前不将完整录音/视频作为产品持久成果保存；日志、截图、转写和总结仍可能敏感。退出、停止和删除行为需要分别验证，不能把关闭页面等同于销毁数据。

`metadata`、`local_full` 和 `off` 等开发采集模式含义见 `dev/observability/README.md`。完整请求捕获、Runtime 数据库与私人调试日志不进入发布快照。
